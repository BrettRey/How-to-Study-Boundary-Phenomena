# Cover letter

Dear Dr Kelih,

Please consider the revised manuscript, “Calibrating Diagnostic Conflict: English Reciprocals in Grammatical Feature Space” (269804392), for the *Journal of Quantitative Linguistics*. Thank you and the reviewers for the opportunity to revise it. Reviewer 2's detailed comments prompted substantial changes to the analysis and interpretation.

The revision compares each reciprocal with explicit personal-pronoun and compound-determinative groups using 154 coded features. The primary analysis recovers all 57 controls and distinguishes the reciprocals from them in both absolute and relative distance. Sensitivity checks show how the modest compound preference depends on morphological coding and phonological weighting. The conclusion is conditional on this representation.

The accompanying response addresses the reports point by point. The supplementary package supplies the matrix, comparator definitions, protocols, scripts, saved results, and separately documented post hoc diagnostics.

Sincerely,

Brett Reynolds
